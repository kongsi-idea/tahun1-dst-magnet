# 磁力创造实验室｜开发 Prompts

## 共同产品约束

- 受众：马来西亚小学一年级，约 7 岁。
- 使用：学校由老师投影、全班参与；家庭由学生独立在电脑或手机操作。
- 单次体验：约 15 分钟；不要求家庭准备真实磁铁。
- 文字：简体中文、短句、学生可自行阅读；不依赖语音。
- 学习：对应 DSKP Sains Tahun 1 7.1.1–7.1.6 与 TP6，但分成多次 15 分钟活动，不在一次体验硬塞完整单元。
- 核心循环：预测 → 操作 → 观察 → 修正 → 解释／创造。
- 线索依次为注意线索、关系线索、操作线索；不直接跳到答案。
- 视觉：现代儿童创造工具；接近真实的实验桌、磁铁和日常物件；不使用 emoji 拼贴、廉价糖果卡片或拟人剧情掩盖科学规律。
- 科学边界：这是概念模拟，不声称精密测量；不可产生“所有金属都会被吸引”“大磁铁必然更强”等错误概念。
- 教师说明：二维模拟不替代真实实验。课堂应配合预测、讨论和真实材料示范，帮助学生迁移。
- 无障碍：触控目标至少 48px；支持鼠标、触控和键盘；尊重 reduced motion；颜色不是唯一反馈。

## Prompt 1：磁力探索桌

建立一个开放实验桌。学生可从托盘拖出磁铁与真实物件，自由移动、旋转和重复测试。不同材料对磁铁呈现连续、可信且一致的反应。铁与多数钢制品受吸引；铝、铜、木、塑料、布和玻璃不受吸引。物件必须显示名称和材料，结果不能只靠颜色表达。

课堂模式提供隐藏结果、预测计票、冻结画面、逐步线索与讨论题。家庭模式提供任务卡但允许自由探索。系统记录首次预测、尝试次数和线索层级。

验收：学生能在新物件上应用材料规律，而不是记住位置；重置后物件位置改变；至少含一个金属但不受吸引的干扰物。

## Prompt 2：磁极谜题场

建立可以旋转和移动条形磁铁的谜题场。学生需要利用同极相斥、异极相吸，使钢珠、小车或活动门到达目标。磁铁的 N、S 标记清楚，可选择隐藏其中一个磁极形成推理任务。显示磁力线时，线条随磁铁位置与方向变化。

每个谜题允许多次尝试；失败保留原题并按三层线索渐进提示。不要用单一“翻转后按测试”的固定流程，学生应直接操作空间布局。

验收：至少三个具有不同空间解法的谜题；学生必须根据运动修正磁极方向；能在没有文字答案的情况下观察相吸或相斥。

## Prompt 3：公平实验室

建立磁力强度公平实验。学生先选择研究问题，再布置磁铁、距离和相同规格的回形针。系统允许改变多个变量，但在学生准备比较时提示是否保持其他条件不变。结果以可吸起的回形针数量和重复测试数据呈现。

学生必须完成至少两组可比较实验，再选择基于证据的结论。系统区分“结果不同”和“实验足以支持结论”。

验收：距离是连续变量；固定磁铁形状和大小；至少重复两次；记录表由操作自动生成；错误设计可以修改而不是直接判错。

## Prompt 4：挑战创造工坊

建立低门槛关卡编辑器。学生选择运送、分拣、迷宫、磁极或公平实验模板，再放置磁铁、目标、物件和障碍。创作者必须先亲自通关，才能保存挑战。保存时选择挑战使用的科学规律。

家庭模式将挑战保存到当前设备，并生成可下载／导入的挑战文件；课堂模式允许老师载入作品让全班试玩。第一阶段不使用帐号、云端或个人资料。

验收：关卡可创建、试玩、返回编辑、验证和保存；未验证关卡不能标记完成；重载页面后本机作品仍存在；导出文件不包含学生姓名。

## 老师控制台 Prompt

为四个工具提供统一控制台：全班暂停、隐藏实验结果、显示逐步线索、显示磁力线、手动预测计票、自动生成讨论问题、查看本次挑战结果、打印实体实验单。课堂投影时控件大且可远距离辨认。家庭模式隐藏教学管理控件。

控制台必须显示以下说明：

> 本工具是科学现象的数字模拟，不替代真实磁铁实验。学生可能难以把二维游戏经验自动迁移到现实，因此课堂使用时，应由老师通过预测、观察、讨论和真实材料示范建立连接。模拟中的距离、速度和磁力线用于帮助观察规律，不代表精密测量结果。
